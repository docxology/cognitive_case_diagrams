# daif

Experimental role-score distributions, pairwise quantile updates, updates under risk distortion, Bayesian filtering, and diagnostics. Legacy Bellman names do not implement a Bellman return backup. VMP is a fixed single-factor softmax; `factor_consistency_score` is the accurate alias for the legacy Bethe function. ERP amplitudes are model units, not microvolts.

Import package exports from `src.daif`; module-specific helpers require their module path. Source signatures are authoritative. Read [method contracts](../../docs/method_contracts.md), the [API index](../../docs/api_reference.md), and [agent notes](AGENTS.md) before changing behavior.

From the project root, use `uv run python scripts/quality_gate.py --coverage`. Tests use real objects and files. Figures are regenerated by `uv run python scripts/generate_diagrams.py`.
