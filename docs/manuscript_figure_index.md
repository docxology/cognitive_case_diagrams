# Manuscript Figure Index

All **30** PNG figures used in *Cognitive Diagrams: Reviewing Categorical Accounts of Linguistic Case* ([`../docs/manuscript/config.yaml`](../docs/manuscript/config.yaml) `paper.title`, v2.3). Generated by `scripts/generate_diagrams.py` (or domain sub-scripts it calls). Three *unpacking companion figures* (table rows 23 through 25) were added to provide pedagogical decompositions of the central category-theoretic constructions in §3, §4b, §4c.

## Rendering Troubleshooting

| Problem | Cause | Solution |
| DisCoPy figures fail | `discopy` not installed or wrong version | `uv pip install discopy>=1.1` |
| Font too small warning | Font size below 16pt floor | Check `FONT_SIZE_LABEL` in `styles.py` |
| Blank figure output | Matplotlib backend issue | Set `matplotlib.use('Agg')` before import |
| DPI too low | Using default DPI (72) | Pass `dpi=FIGURE_DPI` to `savefig()` |
| Figure not appearing in PDF | Wrong path in manuscript | Use `output/figures/{filename}` (relative to project root) |
| Missing labels in bar charts | Text overflow with many categories | Increase `FIGURE_SIZE_DEFAULT` or rotate labels |
| DAIF figures empty | No data passed to plot functions | Ensure `DAIFResult.return_distribution` is not None |
| DAIF quantile fans flat | Uniform return distribution | Check that `push_forward_return()` uses non-trivial `transition_matrix` and `reward_vector` |
