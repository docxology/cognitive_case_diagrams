# quantum

Finite POVMs and density matrices with explicit Hermitian/PSD/normalization checks. The canonical figure uses orthogonal projectors and a diagonal mixture, so it shows classical outcome probabilities, not interference. No quantum hardware, sheaf model, or TQNN is implemented.

| Module | Defined public entry points |
| :--- | :--- |
| [figure_data.py](figure_data.py) | `make_quantum_povm_example`, `make_security_violations_example`, `make_monoidal_functor_example` |
| [quantum_case.py](quantum_case.py) | `CasePOVM`, `case_probability`, `crisp_case_povm`, `graded_case_povm`, `fluid_s_povm`, `semantic_state` |

Import package exports from `src.quantum`; module-specific helpers require their module path. Source signatures are authoritative. Read [method contracts](../../docs/method_contracts.md), the [API index](../../docs/api_reference.md), and [agent notes](AGENTS.md) before changing behavior.

From the project root, use `uv run python scripts/quality_gate.py --coverage`. Tests use real objects and files. Figures are regenerated by `uv run python scripts/generate_diagrams.py`.
