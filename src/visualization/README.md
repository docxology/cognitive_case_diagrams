# visualization

Source-generated diagrams and synthetic numerical plots. Captions, labels, units, and provenance must agree with the data. Never create arbitrary confidence bands, empirical comparisons, or physical interpretations from synthetic scores. DisCoPy is a required project dependency; schematic native drawings are not independent proofs.

Import package exports from `src.visualization`; module-specific helpers require their module path. Source signatures are authoritative. Read [method contracts](../../docs/method_contracts.md), the [API index](../../docs/api_reference.md), and [agent notes](AGENTS.md) before changing behavior.

From the project root, use `uv run python scripts/quality_gate.py --coverage`. Tests use real objects and files. Figures are regenerated by `uv run python scripts/generate_diagrams.py`.

Experiment panels consume stored results. Filtering separates raw replicate variation from uncertainty in the mean; calibration compares coverage with its exact discrete-law target; sensitivity displays every prespecified paired arm with pointwise intervals. These plots use blue marks, neutral reference lines, marker shapes/fills and explicit labels. No empirical language observations are implied. Regenerate experiments before the figures, then inspect the exported panels at their final manuscript scale.

The figure registry (`figure_registry.json`) is written by `src.visualization.figure_registry.write_figure_registry` — the canonical manifest the PDF pipeline and `project_validation` consume. Entry key order, filename sorting, merge semantics, and the byte format are a stable contract; the writer re-verifies the quality input fingerprint before writing and fails closed on unreadable prior registries outside diagnostic mode.
