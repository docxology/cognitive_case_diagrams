# enriched_cat

Candidate hom-matrices, explicit multiplicative composition checks, max-product closure, and matrix magnitude. The standard matrix is synthetic and violates composition before closure. Pseudoinverse magnitudes require valid left/right weighting residuals. Threshold clusters are weak connected components, not pairwise-close cliques.

| Module | Defined public entry points |
| :--- | :--- |
| [enriched.py](enriched.py) | `EnrichedCategory`, `standard_enriched_category` |

Import package exports from `src.enriched_cat`; module-specific helpers require their module path. Source signatures are authoritative. Read [method contracts](../../docs/method_contracts.md), the [API index](../../docs/api_reference.md), and [agent notes](AGENTS.md) before changing behavior.

From the project root, use `uv run python scripts/quality_gate.py --coverage`. Tests use real objects and files. Figures are regenerated by `uv run python scripts/generate_diagrams.py`.
