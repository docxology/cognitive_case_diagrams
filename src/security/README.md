# security

A finite, supplied-label role-policy checker. Unknown roles are rejected before identity checks; mutable category adjacency is refreshed. Assignment checks use pairwise connectivity in either direction, not a directed authorization trace. No text classifier, authentication service, runtime reference monitor, or measured attack detector is provided.

| Module | Defined public entry points |
| :--- | :--- |
| [cognitive_security.py](cognitive_security.py) | `TypeViolation`, `CaseFrameValidator`, `detect_type_violation`, `injection_score`, `topological_robustness`, `semantic_integrity_check` |

Import package exports from `src.security`; module-specific helpers require their module path. Source signatures are authoritative. Read [method contracts](../../docs/method_contracts.md), the [API index](../../docs/api_reference.md), and [agent notes](AGENTS.md) before changing behavior.

From the project root, use `uv run python scripts/quality_gate.py --coverage`. Tests use real objects and files. Figures are regenerated by `uv run python scripts/generate_diagrams.py`.
