Regenerate from source after any plot change, then run the experiments runner if experiment figures changed, inject, and validate the manuscript. The artifact gate verifies files, checksums, labels, per-figure source fingerprints, and counts. It cannot replace visual inspection. The three DAIF plots and the three experiment plots show actual computed synthetic arrays; the POVM figure shows trace probabilities. No fabricated percentile bands, fitted convergence envelope, or empirical microvolt comparison is generated.

The separate [accessibility description source](figure_alt_text.json) describes each figure for nonvisual readers. It is propagated into the registry for PDF and HTML rendering and is subject to the same unbacked-quantity scan as chapter captions.
