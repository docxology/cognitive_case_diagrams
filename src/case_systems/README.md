# case_systems

Finite role graphs, labelled path composition, alignment maps, and natural-transformation helpers. Endpoint and weight predicates do not certify arbitrary categories or functors. `MonoidalFunctor.preserves_tensor()` is a role-separation policy, not a monoidal-law test. Fluid-S probabilities are supplied modeling inputs.

| Module | Defined public entry points |
| :--- | :--- |
| [case_category.py](case_category.py) | `CaseRole`, `Morphism`, `CaseCategory`, `standard_case_category`, `minimal_case_category`, `introductory_case_category`, `accusative_alignment`, `ergative_alignment`, `tripartite_alignment`, `active_stative_alignment` |
| [fluid_s.py](fluid_s.py) | `VolitionContext`, `FluidSFunctor`, `create_fluid_s_functor`, `bats_fluid_s`, `fluid_s_enriched_weight` |
| [functor.py](functor.py) | `AlignmentFunctor`, `accusative_to_ergative_functor`, `tripartite_functor`, `MonoidalFunctor` |
| [natural_transformation.py](natural_transformation.py) | `ComponentMorphism`, `NaturalTransformation`, `IdentityNaturalTransformation`, `compose_transformations` |

Import package exports from `src.case_systems`; module-specific helpers require their module path. Source signatures are authoritative. Read [method contracts](../../docs/method_contracts.md), the [API index](../../docs/api_reference.md), and [agent notes](AGENTS.md) before changing behavior.

From the project root, use `uv run python scripts/quality_gate.py --coverage`. Tests use real objects and files. Figures are regenerated by `uv run python scripts/generate_diagrams.py`.
