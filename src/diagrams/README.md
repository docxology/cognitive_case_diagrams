# diagrams

Explicit DisCoPy pregroup constructions, tensor examples, diagram counts, and entity-name bookkeeping. `Discourse` does not infer coreference or implement a complete DisCoCirc semantic state update. `MagnitudeHomologyMetrics` contains a synthetic cup/cap score, not homology or measured decoherence.

| Module | Defined public entry points |
| :--- | :--- |
| [complexity_examples.py](complexity_examples.py) | `build_complexity_examples` |
| [complexity_metrics.py](complexity_metrics.py) | `DiagramMetrics`, `count_boxes`, `count_words`, `count_cups`, `count_caps`, `diagram_depth`, `diagram_width`, `compute_normal_form`, `is_in_normal_form`, `diagrams_equal`, `analyze_diagram`, `syntactic_complexity_score`, `compare_diagrams`, `MagnitudeHomologyMetrics`, `compute_pqc_decoherence_proxy` |
| [ditransitive.py](ditransitive.py) | `DitransitiveSentence`, `create_ditransitive`, `create_discopy_ditransitive` |
| [string_diagram.py](string_diagram.py) | `AtomicType`, `Wire`, `Box`, `Sentence`, `Discourse`, `create_discopy_transitive`, `create_discopy_complex_transitive`, `create_discopy_intransitive`, `create_discopy_passive`, `create_discopy_snake_equation`, `create_discopy_composition`, `create_discopy_multilingual`, `create_word_diagram_transitive`, `create_word_diagram_intransitive`, `create_swap_passive`, `create_word_diagram_ditransitive`, `create_tensor_semantics` |

Import package exports from `src.diagrams`; module-specific helpers require their module path. Source signatures are authoritative. Read [method contracts](../../docs/method_contracts.md), the [API index](../../docs/api_reference.md), and [agent notes](AGENTS.md) before changing behavior.

From the project root, use `uv run python scripts/quality_gate.py --coverage`. Tests use real objects and files. Figures are regenerated by `uv run python scripts/generate_diagrams.py`.
