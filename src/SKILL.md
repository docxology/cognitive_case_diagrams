# Source workflow

Read [README.md](README.md), [AGENTS.md](AGENTS.md), and the selected package's README/AGENTS/SKILL files. Source signatures and tests are authoritative. Distinguish implemented numerical examples from theoretical or empirical claims using [method contracts](../docs/method_contracts.md). Keep algorithms in source and scripts thin. Run the project quality gate and artifact validation after regeneration.
