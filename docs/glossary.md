# Glossary

| Term | Meaning and boundary |
| :--- | :--- |
| Morphological case | A language-specific marking distinction, not a universal semantic role |
| S / A / P | Core argument primitives; see the manuscript alignment section |
| Case graph | A specified role set and labelled relations |
| Pregroup reduction | A typed ordered contraction under assigned lexical types |
| DisCoCat | Composition of semantic representations guided by grammatical structure |
| Discourse history | Explicit entity-name and role bookkeeping in this project |
| Enrichment | Hom-values satisfying unit and composition axioms in a chosen base |
| Magnitude | Weighting/coweighting sum when those equations have solutions |
| Morita equivalence | Equivalence of classifying toposes; not a count comparison |
| Variational free energy | A quantity relative to a specified generative model |
| Quantile | Generalized inverse CDF value; reconstruction conventions matter |
| POVM | Positive Hermitian effects summing to identity |
| Security role policy | Rules over supplied labels; not authenticated operational enforcement |
| ERP proxy | A model quantity without physiological calibration |

[Manuscript notation](manuscript/11b_notation.md) and [method contracts](method_contracts.md) provide exact context.
