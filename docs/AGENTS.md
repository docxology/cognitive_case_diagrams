# Documentation agent guidance

Follow [project guidance](../AGENTS.md). [README.md](README.md) inventories the authored references; `modules/` and `manuscript/` carry their own guides. Generated `output/`, dependencies, caches, and dot-directories are outside this documentation pass.

Source signatures, current test receipts, and configuration are authoritative. Do not repeat fixed counts without recounting them. Keep [method contracts](method_contracts.md), [claim ledger](claim_ledger.md), captions, and source docstrings aligned. Mathematical background may be included without a local implementation if clearly identified; do not claim every equation executes.

Use primary literature for technical claims. Synthetic inputs cannot justify empirical intervals or physical units. Figure source typography uses the project's 16-point floor, and final rendered readability requires visual inspection. Do not lower the 90% coverage floor or use mocks. After documentation changes, validate links, manuscript hydration, figure registry, and final renders as applicable.
